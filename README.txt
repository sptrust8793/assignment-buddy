# AssignmentBuddy Website

Open `index.html` in a browser to preview.

WhatsApp contact is configured for **+91 87370 52664**.

To publish free on GitHub Pages:
1. Create a GitHub repository, e.g. `assignment-buddy`.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Choose Deploy from branch → `main` → `/root`.
5. Save and open the generated GitHub Pages URL.

The assignment form does not store data; it creates a WhatsApp message with the student's requirements.
